    addition        (+)
    subtraction     (-)
    multiplication  (*)

Additionally, the program should handle operands and display the final result.

The program should:
- handle single-digit operands
- handle multi-digit operands
- handle valid postfix expressions.
- Display an error message for invalid expressions.
- Display the result for valid expressions.

    args = []
    while stack:
        top = stack.pop()
        if top is numeric: args.push( int(top) )
        else:
            b = args.pop()
            a = args.pop()
            switch (top) {
                case "+": args.push(a + b)
                case "-": args.push(a - b)
                case "*": args.push(a * b)
                case "/": args.push(a / b)
                case "%": args.push(a % b)
                default: raise Exception
            }
    if args.size != 1: raise Exception
